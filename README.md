# Python Application Testing using Pytest and Hypothesis

## Aim
To write comprehensive unit and integration tests for a Python
application using Pytest and Hypothesis.

## Requirements
- Python 3
- Pytest
- Hypothesis

## Installation

Install Pytest:

pip install pytest

Install Hypothesis:

pip install hypothesis

## Files

calculator.py
test_calculator.py

## Testing

Run the following command:

pytest -v

## Testing Types

1. Unit Testing
   Tests individual functions separately.

2. Integration Testing
   Tests multiple functions working together.

3. Property-Based Testing
   Hypothesis automatically generates different inputs
   and verifies the expected properties.

## Expected Result

All test cases should pass successfully.

Example:

6 passed

## Conclusion

The Python application was successfully tested using Pytest
and Hypothesis. Unit, integration, and property-based tests
were performed successfully.
